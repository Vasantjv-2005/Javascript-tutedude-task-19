# Service Booking Website

## About the Project

The Service Booking Website is a simple web application that allows users to browse different services, add their favourite services to a cart, view the total amount, and book services easily.

The website provides a simple and user-friendly interface with different service options.

## Technologies Used

- HTML5 – Used to create the webpage structure.
- CSS3 – Used to design and style the website.
- JavaScript – Used to add interactive functionality.

## Features

1. Navigation bar with Home, Services, About Us, and Contact Us.
2. Displays the username and Logout button.
3. Shows available services with images and prices.
4. Allows users to add services to their cart.
5. Provides an option to skip unwanted services.
6. Displays selected services in the cart.
7. Calculates the total amount automatically.
8. Allows users to remove services from the cart.
9. Includes a booking form with Full Name, Email, and Password.
10. Displays a booking confirmation message after successful submission.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Make sure all four files are in the same folder.
4. Open the `index.html` file in Google Chrome.
5. Browse the available services.
6. Click the Add Item button to select services.
7. Check the cart and total amount.
8. Click Book Now and enter your details.
9. Submit the form to see the booking confirmation.
